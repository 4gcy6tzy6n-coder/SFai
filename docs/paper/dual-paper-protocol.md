**目标:** ICML 2027 Main Conference 双投

**分离总原则（不可违反）：**

## 一、不可被替代的科学贡献（核心论证）

### Paper A 的独有贡献（B 不能声称）

1. **形式化测量协议**：报告成功 C / 真实成功 Y / 验收放行 A 三元语义，及六指标
   （True Success、Claim FS、Delivered FS、Accepted Error Rate、Valid Success
   Recall、False Rejection）——这是**评价科学**贡献，与任何架构无关；
2. **评测偏差的实证发现**：现有评测漏掉假成功、判分器自身会失效（P0 审计已证：
   三个判分 bug 模拟出"模型失败"）、零假成功可来自零成功（平凡零问题）；
3. **框架无关基准构造方法**：独立环境真值、评分文件保护、标准答案正向自检、
   双分母口径、配对统计规范——可复用到任何 Agent 系统；
4. **跨模型/跨框架可靠性普查**（18 模型 × 4 框架）：偏差如何随模型/框架系统性变化。

**A 的一句话主张：** "Agent 评测必须测量'声称 vs 真实'的偏差；我们给出协议、
基准与普查，并揭示评测自身的失效模式。"

### Paper B 的独有贡献（A 不能声称）

1. **Decide-Act 机制**：模型原生逐步动作控制（9 类意图）+ 运行时安全执行——
   这是**架构设计**贡献；
2. **Capability × Context 联合协调**：按需激活（能力/技能 + 稀疏工作集）的协同
   收益——需联合消融证明；
3. **Index/Wiki/Way 分层记忆**（Way=方法/出错记忆，AI 自写自记）——记忆架构贡献；
4. **可验证执行 Runtime**：策略分级/审批收据/幂等/有界修复/恢复——系统贡献；
5. **机制有效性证据**：E8 路由消融（适应性）、E10 等验证器对照（运行时鲁棒性
   12/12 vs 裸异常）、故障注入恢复（待做）。

**B 的一句话主张：** "模型原生自路由 + 按需激活 + 可验证执行构成更有效的 Agent
架构；我们给出机制、系统与因果消融。"

### 边界裁决规则（写作时执行）

| 若结论是…… | 归属 |
|---|---|
| "现有评测漏了 X / 指标应这样定义" | **A** |
| "验证/修复改变了成功率-风险-成本权衡"（作为机制效果） | **B**（A 只引作普查现象） |
| "假成功率在 18 模型上是 0.324"（现象普查） | **A** |
| "Decide-Act 在 long-horizon 1.00 vs 0.00"（机制因果） | **B** |
| 判分器审计方法论（标准答案自检/评分保护） | **A** |
| Rust/并发/内存/冷启动 | **B**（附录级） |
| 三层记忆、稀疏激活成本曲线 | **B**（A 引用为被测系统特性） |

## 二、假设与实验矩阵

### Paper A 实验（A1–A6）

| ID | 假设 | 设计 | 现状 |
|---|---|---|---|
| **A1** 测量协议有效性 | 六指标比单一成功率更能区分机制 | Y/C/A 标注 + 指标计算框架 | 指标已定义，编码中 |
| **A2** 判分器审计 | 判分器自身失效会产生虚假"模型失败" | 标准答案自检 + 三 bug 案例 + 评分保护 | ✅ P0 完成（可直接写） |
| **A3** 跨模型普查 | 假成功随模型/框架系统变化 | 18 模型 × 4 suite（已有）+ 扩样 CI | ✅ 已冻结（72 格） |
| **A4** 跨框架普查 | 无验证层框架静默交付错结果 | 4 框架同模型同判分（已有）+ 统一接口 | ✅ E7v2 + E10 |
| **A5** Agent 原生环境 | 偏差在真实工具环境更大 | **AppWorld/τ-bench 迁移**（独立判分） | ❌ P0 缺口 |
| **A6** 协议对照 | 新协议 vs 旧口径结论可翻转 | 同数据两种打分对照 | ❌ 待做（数据已有） |

### Paper B 实验（B1–B6）

| ID | 假设 | 设计 | 现状 |
|---|---|---|---|
| **B1** Decide-Act 因果 | 自路由在不确定任务优于固定管线 | E8 扩样（n=16+）+ 难度分层 | ⚠️ n=4 待扩 |
| **B2** 联合协调收益 | Capability×Context 联合 > 单独 | 2×2 消融（动态激活 开/关 × 稀疏上下文 开/关） | ❌ P0 新做 |

### 共享基础设施（数据共享规则）

- A3/A4/B1/B3 共用 bench v0.2.2+ 与冻结任务集；**A 负责判分器有效性**（自检协议），
  **B 引用 A 的协议**（同期匿名引用）。
- A5/B4 共用 AppWorld/τ-bench 适配器；A 用它测偏差，B 用它测机制——**结果独立
  报告，不复用对方表格**。
- sfai 在 A 中只是被测对象之一（公平接口）；B 的对照框架必须独立于 A 的定制判分。
