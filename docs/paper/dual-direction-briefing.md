## 一、Paper A —— Agent 可靠性评测（我的方向）

### 1. 问题：行业都在报"成功率"，但没人验证交付物

Agent 说"任务完成"≠环境真的对了。已有研究（2026 年 4 篇）已发现假成功现象本身——**所以我们不主张"首次发现"**，我们的重心是：

> **构建可审计的评价协议，并证明它如何系统性改变可靠性测量结果。**

### 2. 四个贡献

**① Y/C/A 评价协议（形式化核心）**
- 三元语义：**Y**=独立环境真值 / **C**=Agent 声称完成 / **A**=验证门放行——声称与交付首次分离
- 六指标：True Success、Claim FS、Delivered FS、**Accepted Error Rate**（交付可信度）、Valid Success Recall、**SONDR**（真实成功未交付率）
- 新增 **ErrorClaim P(C=1|Y=0)**：区分"任务做不好"与"做错仍声称"
- 统计纪律：McNemar 配对检验、零分母→N/A、Y∈{0,1,⊥} 不可判定、Y_pre/Y_post 时间截面

**② 判分器审计（方法论贡献）**
- **双控协议**：官方标准解必须满分（正控 10/10）+ 初始态不得满分（负控 24% 地板）
- **HumanEval 事故案例**：3 个判分 bug 把真实正确率 1.00 的模型显示成 0.00，并伪造出"验证门奇迹"——**坏判分器会虚构科学结论**
- **故障注入（A8）**：6 种故障型 × 盲测设计——**18/18 检出、盲测 6/6、0 误报**；盲测还发现了审计规则自身的排序缺陷（泛化证据）
- 验证器消融（A11）：同一批候选上，**确定性规则 24/24 检出/0 误报，帕累托优于 LLM 判官**（0.79–0.88/0.17）

**③ 跨模型 + 跨环境可靠性普查**
- 合成套件：18 模型 × 72 格（有门假成功 0.000 vs 无门 0.324）
- **Agent 原生环境（AppWorld，独立终态判分）**：6 模型 × 80 运行——真实成功 0.69 vs 声称率 0.88（**缺口 0.19，21% 的声称是假的**）；假声称率 0.00–0.42 因模型而异
- 公开基准：GSM8K / HumanEval / SpreadsheetBench（NeurIPS D&B 公开任务集要求达成）
- 第二环境 τ2-bench 接线完成（多轮-用户交互），试点 n=5，扩样在计划中

**④ 协议有效性四臂对照（A7）**
- 同一批运行上比较：Agent 自报 / 官方评分 / 已有 false-success 口径 / 我们的 Y/C/A
- **已命中 D4**：部分分排名 ≠ 真实成功排名（地板扭曲，E1–E3 都看不见）
- 预注册 D1–D4 差异点（跑前选定，防事后挑选），D1 待 A9 扩样

## 二、Paper B —— Decide-Act 架构（另一团队方向）

### 1. 问题：Agent 执行体系能否更有效？

不是"再包一层 LLM"，而是三件事的组合：
- **模型原生自路由**（Decide-Act）：每步模型自己决定动作，运行时兜底
- **按需激活**：能力/Skill + 稀疏上下文（成本不随规模涨）
- **可验证执行**：策略分级、审批、幂等、有界修复的 Rust 运行时

### 2. 机制主张与证据

| 主张 | 证据 |
|---|---|
| **Decide-Act 自路由**在不确定任务上决定性 | E8 消融：long-horizon **1.00 vs 固定管线 0.00**（诚实双向：流程化任务固定管线更优——"适应性换开销"） |
| **可验证执行运行时**更鲁棒 | 等验证器对等实验：**12/12 完成 vs 裸框架 10/12**（异常丢任务） |
| **三层记忆 Index/Wiki/Way** | Way 层记每任务方法/优点/**出错重点**，AI 自写自记（对齐并扩展 Claude Code 记忆架构） |
| **稀疏上下文 + Rust** | 78× 上下文成本差（160 文档历史）；GIL **5.1× vs 1.0×** 并发扩展；冷启动 255×–378× |

### 3. 边界（诚实）

- 自路由**非处处更优**（E8 双向结果如实呈现）——定位为"不确定性任务的适应性优势"，混合路由是 future work；
- 验证门收益随模型错误率放大（低错误任务上门不触发——E10 对等实验如实呈现）；
- 18 模型假成功普查、跨框架对照等**评测类结果引用 Paper A 的协议**（同期匿名引用）。

### 4. 交接与共建

- 框架团队拿走：B0–B4 因果消融流水线（已验证判分 12/12）、AppWorld 工具契约、E8/E10 结果；
- Paper B 至少一项**独立于新 benchmark** 的架构验证（双投门禁 #5）。
