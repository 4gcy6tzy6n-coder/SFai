# 统计检验与比率分解（回应导师风险 #1、#2）

**假成功定义（benchmark-spec v0.2.2 口径）：**
- 主指标 `fs_over_all` = 假成功 / **全部运行**（现表格口径）
- 条件指标 `fs_over_claimed` = 假成功 / **声称成功的运行**（假发现率）
- 假成功 = 状态 completed 且 (验收失败 或 交付物错误)。拒绝/阻塞**不计**假成功，单列。

### 关键澄清：零假成功 ≠ 零成功
