## 🔴 门禁 #1：Reciprocal Reviewing 资格核对表（需导师逐项确认）

**规则要点（据 ICML 2027 CFP）：**
1. 资格 = 截至 **2027-01-14** 前，作者至少有一篇被**指定会议/期刊**录用的合格论文
   （ICML、NeurIPS、AAAI、CVPR、IROS 等在官方名单；**Workshop/Short/Industry
   Paper 不计**）；
2. 若一篇论文**所有作者都无资格** → 该投稿可获互惠审稿**豁免**，但**同一作者最多
   只能参与一篇豁免投稿**；
3. 双投场景下：两篇都应至少有一位有资格的共同作者担任 Reciprocal Reviewer；
4. 署名必须真实贡献（不能为凑资格挂名）；**摘要截止（01.14）后不得增删作者**。

**核对清单（请导师/作者填写）：**

| 作者 | 拟署名论文 | 合格录用经历（会议/期刊 + 时间） | 满足资格？ | 角色（Reviewer？） |
|---|---|---|---|---|
|  | A / B / 两篇 |  | 是 / 否 |  |
|  |  |  |  |  |
|  |  |  |  |  |

**决策树：**
- 两篇各有 ≥1 名有资格作者 → 正常双投 ✅
- 仅一篇有 → 另一篇走豁免（注意"一人仅一篇豁免"限制）⚠️
- 都没有 → **两篇不能同投**（豁免只能用一次）→ 需二选一或调整署名 ❌

**⚠️ 截止时间影响**：作者名单在 **01.14 摘要截止后锁定**——资格确认必须在
**12 月中旬前**完成，以免影响署名调整空间。
